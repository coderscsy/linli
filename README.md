# OliviaSoul · 林离离线增强工具

面向已安装《BSide: Olivia Lin》离线客户端的 Windows 本地工具，提供信件与记忆管理、兼容 AI 接入、成品演奏视频导入、游戏端“我的上传”播放与作品编辑，以及轻量桌面歌词。

不提供游戏本体、官方账号数据或官方演奏视频，不恢复已关闭的官方服务器。

## 快速开始

1. 安装 Windows x64 安装包，或将便携包完整解压到独立、可写的目录。**不要放进游戏目录，不要直接在 ZIP 内运行，也不要同时运行安装版和便携版。**不需要另装 Node.js 或运行 npm。
2. 打开 OliviaSoul，等待本机服务就绪。“AI 模型”中选择远程/本地兼容 API，填写自己的地址及鉴权信息，点击“查询模型列表”，选择模型，再“保存并测试”。检测成功后点击“检测并设为当前模型”才启用。
3. 本地模型服务需要用户自行启动；OliviaSoul 不负责启动 Ollama、LM Studio 等程序。仅导入/播放已有作品不需要 AI 生成视频。
4. **先关闭游戏**，进入“客户端与桌面”选择正确的游戏 exe，点击“启用服务”，等待明确成功，再从 Steam 启动游戏。后续使用本地功能时，应先开 OliviaSoul 并保持后台运行，再开游戏。
5. “官方作品”中选择包含成品 MP4 的文件夹，点击“扫描预览”，核对可导入/跳过项目后“确认导入”。在游戏曲库的“我的上传”中查看、播放或编辑。
6. 需要歌词时，在“歌词设置”启用；上传作品可在“名称 / 时段”编辑器导入 LRC。同一作品的视频版本默认共享文本、分别保存偏移；游戏底部“词”按钮可随时开关。

R10.7 新增的手动模型名、中转地址及响应兼容处理见 [模型与中转 API 兼容说明](docs/MODEL_API_COMPATIBILITY.md)；配置步骤见 [API 配置使用说明](source/local-service/packaging/API配置使用说明.md)。旧的 R10.6 安装包不包含这些改动。

关闭管理窗口会隐藏到托盘；托盘“退出”会立即收起窗口，随后结束后台清理。**停用服务**是还原游戏客户端的本地接入补丁，不等于退出 OliviaSoul。启用/停用期间不要强制结束程序；若失败，保留报错并反馈。

## 导入音乐：请先核对内容，再校正名称

[玩家上传音乐分享链接](https://ug.link/sycan/filemgr/share-download/?id=8c2b2c05b0ce4dd19c5e1c89e47e57e3)

此链接由维护者提供，资源独立于软件安装包，来源致谢见文末。下载可用性及资源内容以分享页为准；软件不会自动下载整套曲库。请仅使用有权使用的媒体，下载后保留作品目录结构，再到“官方作品”扫描预览并确认导入。不要将文件数当作歌曲数，同一歌曲可能有多个时段视频。

导入名称可能来自目录名、分享记录或 library.json，原始整理数据本身可能有错。**软件不会听歌识曲，也不能保证导入名称就是视频里的歌曲。**

- 在后台“官方作品 → 我的上传”或游戏“我的上传”点击“名称 / 时段”，打开同一套编辑器，展开预览核对歌曲。
- **“保存”**：修改显示名称。
- **“永久保存曲名”**：纠正正式名称，并保存内容匹配记录；保留用户数据和同一媒体内容时，重新导入可沿用。不会重命名视频文件、搬动目录或改变视频绑定。
- “恢复正式名称”只撤销显示别名；已永久纠错的名称不会因此退回最初的错误名称。再次永久保存可继续纠正。
- 一首作品的白天、傍晚、夜晚视频是同一作品的变体，只改一次作品名称，不需要给三个视频分别取歌曲名。要确认歌曲可先听一个片段；要确认时段，需要查看各片段画面。
- 对哈希文件名、DEFAULT、ALT_2、ALT_3，**不能根据排序猜时段**。有明确时段信息时自动匹配；没有明确标记时请在编辑器手动选择白天/傍晚/夜晚。
- 本机时间范围：白天 06:00–16:00；傍晚 16:00–20:00；夜晚 20:00–次日 06:00。保存时段用于下次播放，不强行切换当前演奏。

永久纠错依赖 UserData 中的数据库和纠错记录，不是上传到云端的曲名库。换电脑应备份完整 UserData；不要只保留 MP4 后删除全部用户数据。

## 路径、备份与注意事项

- 默认**引用导入目录**，不自动搬走或统一复制视频。请保留源文件；若文件夹改名或位置改变，应重新扫描并确认导入，以核验内容并补记来源。移动硬盘/网络盘需保持可访问。
- 只读获取游戏保存路径；修改游戏路径不等于自动迁移旧视频。需要迁移时，在“客户端与桌面”先预览、核对空间，再明确确认；迁移成功后使用迁移位置，来源文件保留。
- 数据位于 `<安装目录>\UserData\`；信件数据库在 `database\olivia-local.sqlite`，可读档案在 `信件往来\`。视频可能仍在外部引用目录，应一并备份。
- 升级前从托盘完全退出，备份 UserData；在同一目录升级，保留 UserData。不建议卸载后再安装来升级。旧 C 盘版本的数据位置可能不同，请先导出/备份。
- `.soul` 导入是覆盖式恢复，会替换当前记忆、摘要和关联视频，请先导出备份。它不等于完整的作品库及所有设置备份。
- 每日写信默认 3 封，用户可设置整数 0–999；**0 表示当天不能写信，不是无限次数**。升级保留已保存的数量。
- 缺少 WebView2 Runtime 时，首次启动可能需要联网安装微软运行时。包内已有 Node.js、FFmpeg、whisper.cpp 和 Whisper small；首次预览大视频或从网络盘读取可能较慢。
- 对映射网络盘游戏路径，请正常启动 OliviaSoul，不要手动改为管理员运行；提权上下文可能看不到原盘符。启停前请关闭游戏。
- 游戏原有暂停/停止入口仍结束当前演奏并回到默认壁纸；**歌词工具栏的暂停/继续**则保留当前演奏进度与歌词。播单内自然结束按当前播放模式推进；不在播单的单独播放结束后退出演奏。
- 没有 MIDI 上传、MIDI 视频生成、FluidSynth/Godot 琴键渲染或自动人物演奏。“定制演奏”隐藏；只有 MIDI、没有有效成品 MP4 的目录会跳过。

## 隐私与反馈

公开包不应包含个人密钥、信件、数据库、日志、账号 Cookie 或曲库。使用远程 AI 时，相关信件/记忆/转写文本会按功能发送到用户配置的接口；“本地数据保存”不等于所有 AI 请求都离线。不要公开上传完整 UserData 或 .soul 文件。

## 升级与卸载

- **升级**：退出游戏和托盘程序，备份整个 UserData 与外部媒体，运行新安装包并沿用原安装目录，无需先卸载。
- **安装版卸载**：先退出游戏、Steam 和 OliviaSoul，再通过 Windows“已安装的应用”卸载，或运行安装目录内的 `unins000.exe`。
- 卸载器会预检并恢复已登记、可验证的客户端网页、播放器、受支持 DLL 补丁和严格匹配的 Steam 启动项；不修改游戏 `usersettings.dat`。
- 路径失效、备份不可信、文件后来被改动或权限不足时，卸载中止并保留恢复材料。不要强行删除安装目录；解决提示后重试。
- UserData 默认保留，外部来源视频不会被删除。便携版无安装式卸载器，请先逐个停用曾挂载的客户端并恢复使用过的 Steam 启动衔接，再移除程序目录。
