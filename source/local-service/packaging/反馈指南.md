# Bug 与功能建议

欢迎积极反馈问题，也欢迎告诉我们“你希望下一版解决什么”。反馈入口：[coderscsy/linli Issues](https://github.com/coderscsy/linli/issues)。提交前可搜索已有问题，避免同一问题的信息分散；已有问题也可以补充可复现步骤。

```text

操作步骤：
1.
2.
3.

预期结果：
实际结果 / 完整错误文字（先脱敏）：

最后一次正常时的情况：
近期是否改名、改路径、迁移、更新游戏或验证游戏文件：
```

## 音乐与播放问题请额外说明

- 是管理页预览，还是游戏端正式播放？是直接点播，还是播单自动切换？当前什么播放模式？
- 只影响一首、某个时段，还是所有作品？本机时间和编辑器中的时段映射是什么？
- 用系统播放器打开“该作品实际引用的源文件”时，内容是否正确？源文件是否存在且能播放？
- 名称是目录原名、显示别名还是永久纠错名？不要因为名称相同就假设视频内容相同。
- 如果源视频本身与目录名称不符，可以先预览并“永久保存曲名”；若选择 A 后确实播放了另一个文件 B，请注明对应关系。
- 卡顿发生在加载、约 2 秒、拖动后、暂停后还是自然结束时？时间轴和桌面画面是否一致？
- 提供编辑器截图、文件数量/时长/编码信息即可。**不要默认把整首歌曲或整段官方视频公开上传到 Issue。**

## 模型与信件问题请额外说明

压力测试/闪退反馈请附：连续播放了多久、播单顺序（官方/用户上传）、循环模式、闪退前最后一次操作、准确时间，以及当时任务管理器“内存”页的截图（注意脱敏）。`0xE0000008` 表示内存分配失败，不能单凭错误码确定占用来源。完整 `.dmp` 转储可能包含密钥和私人内容，请勿直接公开上传。


- 远程还是本地兼容 API？处于查询、保存测试、启用还是生成回信阶段？
- 显示的状态和错误码是什么？网络是否通过代理？本地服务是否已自行启动？
- 当日上限和剩余次数是多少？0 表示不允许写信。
- 不要贴真实 API Key、授权请求头、Cookie、私有接口域名或信件全文。通常只需要状态、错误码和脱敏后的短日志。

## 功能建议模板

```text
标题：[建议] 希望增加/改进的功能

使用场景：我在什么情况下需要它？
当前不方便之处：
希望的操作方式 / 最终效果：
它能解决什么问题：
使用频率和优先级：
是否有界面草图、参考或替代方案（可选）：
```

建议可以很小，例如某个提示更清楚、列表更好用、导入过程更易理解；请尽量描述场景，而不仅写“优化一下”。现阶段不开发 MIDI 视频生成或自动人物弹奏。

## 安全提交材料

- 日志通常在 `<OliviaSoul安装目录>/UserData/runtime.log`；只截取问题发生时间附近的相关片段，提交前自己检查。
- 将个人姓名、用户名、UID、私有地址和完整磁盘路径替换为 `<用户>`、`<接口>`、`<媒体目录>` 等占位符。
- **不要上传整个 UserData、数据库、.soul、settings、client-backups、Steam 配置备份或浏览器配置。**这些文件可能包含密钥、个人信件和账号信息。
- 不要公开发送密码、API Key、Cookie、验证码、授权头或完整服务端错误正文。截图也要检查地址栏、输入框和背景窗口。
- 一时无法复现也欢迎反馈，但请标明发生时间和频率；不要为了复现而删除数据、强杀进程、关闭系统安全功能或反复覆盖客户端。

谢谢每一份可复现的反馈。它能帮助维护者区分软件缺陷、源文件问题和环境差异，也帮助确定下一轮改进的优先级。
