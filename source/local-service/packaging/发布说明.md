# OliviaSoul R10 · 2008.2.7-linli.2

## 本次整理

- 官方已完成 MP4 导入、作品分页/搜索与游戏“我的上传”播放；纠正作品 ID、媒体源和时段变体的对应关系，处理播单切换、时间轴、拖动与结束状态问题。
- 播单自动切换到本地上传内容时，处理曾出现的开头约 2 秒停止问题；暂停/停止沿用游戏结束当前演奏并恢复默认壁纸的逻辑。
- 前后台共用“名称 / 时段”编辑器和预览；优化首次媒体读取及缓存使用，支持显示别名与永久曲名纠错，避免仅改名导致播放源失联。
- 每日写信默认 3 封、用户可设 0–999；0 表示无发送次数。信件与记忆的本地保存、档案同步及视频附件保留。
- 整理管理页的左右布局、独立滚动、作品与记忆编辑布局；AI 模型查询后选择、保存测试和启用分开，允许文本框右键编辑。
- 修复服务启用/停用中的备份验证和执行路径处理；映射网络盘使用当前用户环境，错误时不强行覆盖不可信备份。
- 托盘“退出”立即收起管理窗口，再收尾后台；防止清理期间重复关闭或重新弹出窗口。
- 游戏客户端补丁改用多客户端登记册；安装版卸载前先恢复所有可验证的活动补丁与严格匹配的 Steam 启动项，任何异常都会中止卸载并保留恢复材料，不触碰游戏 `usersettings.dat`。
- 修复 AI 状态栏在侧栏占用、窄窗口和长模型名下互相挤压的问题；公开包在 staging 与便携 ZIP 阶段检查私人模型、接口、路径、密钥和运行时数据。
- 修复 r9 遗漏原生小组件补丁的问题：启用服务时同步修复 0.0.9.627 客户端的写信、音乐入口隐藏判断。只安装网页 v31 补丁不再判为完整挂载；已有 v31 可补齐，保留当前同端口播放器。两个原生文件先验证、备份，再修改；停用服务与卸载使用登记备份恢复。
- 普通启动不再从旧安装目录自动继承模型地址、模型名或 API Key；AI 页新增“清除模型配置”，只清除模型相关文件，不影响信件、数据库、曲库、媒体与名称纠错。
- 管理页 HTML、CSS 与 JavaScript 禁用缓存；本机曲目路径默认折叠，需要时手动展开查看，避免升级后仍显示旧页面或默认暴露本机路径。
- 补齐发行白名单遗漏的桌面模块，并将当前使用说明、更新内容和反馈指南放入安装/便携包。

## 请特别注意

1. **曲名可能来自错误的原始目录/清单。**本版本不自动听歌识曲。请预览确认后使用“永久保存曲名”；它纠正作品信息，不改视频文件名、路径、作品 ID 或时段绑定。
2. **三个时段一般属于同一作品。**歌曲名称改一次即可。确认歌曲可先听一个代表片段；确认时段需看各变体画面。DEFAULT/ALT/哈希文件名不代表白天或夜晚，无可靠标记请手动对应。
3. **默认引用源目录，不自动迁移。**导入后必须保留原文件，网络盘/移动盘需保持可访问；只有明确确认迁移才复制到目标位置。
4. **永久纠错要保留用户数据。**升级/换电脑备份整个 UserData 和外部视频目录；删掉纠错记录后，仅靠文件名不能找回改名结果。
5. **先开 OliviaSoul，再开游戏。**启用/停用服务前先关闭游戏。托盘退出不等于停用服务，停用服务也不等于退出管理程序。
6. **MIDI 生成已下线。**不再提供 MIDI 上传生成演奏、Godot/FluidSynth 琴键视频或自动人物演奏，仅导入现有有效 MP4。
7. **升级保留 UserData。**请先备份，再在同一独立安装目录更新；.soul 导入属于覆盖恢复，不是合并所有现有记忆。
8. **Steam 单击启动衔接是可选排障工具。**随包附工具和说明，不在安装或启动时自动改用户 Steam 启动项；没有问题不必配置。
9. **升级会保留当前安装目录的 UserData。**若原安装目录已保存模型配置，可在“AI 模型 → 重置模型配置”中明确清除；新版本不会再从其他旧安装目录自动导入。曲目路径仍由游戏设置只读取得，并非公开包内数据。
10. **安装版卸载会先恢复客户端。**请先退出游戏和 Steam。路径、备份、哈希、权限或用户后续修改无法安全确认时，卸载会停止并保留程序与恢复材料；不要绕过提示直接删目录。

## 验证边界

维护者环境已反馈验证服务启停、作品播放/改名、托盘退出，以及 R10 写信与音乐入口的恢复。公开包的校验文件用于核对下载完整性；本机验收不能代替每台电脑、不同安装路径及后续游戏版本的实际验证。

本工具不提供游戏/官方视频/账号数据，不保证任意游戏更新版本兼容，不保证网络接口始终可用。首次预览大视频、网络盘读取或首次安装 WebView2 可能需要等待。遇到异常请保留错误信息，不要靠删除数据库、强行覆盖备份或连续点击来尝试恢复。

本包未配置代码签名，Windows 可能显示未知发布者。请核对可信来源和 SHA256SUMS.txt，不要关闭安全软件。
