# OliviaSoul R10.4 稳定性更新 · 2008.2.7-linli.6

构建日期：2026-09-06。程序版本保持 `2008.2.7`，更新标识升为 `2008.2.7-linli.6`。本次为包含全部历史功能的完整安装包和便携包。

## R10.4 重点更新

- WebPlayer v14 将命令轮询调整为每秒一次并禁止重叠，播放进度每秒最多上报一次，同时主动释放响应体和过期请求。
- 四小时压力测试共 952 次采样，0 采样错误、0 新崩溃，提交内存峰值 36.82%，游戏私有内存未持续增长。
- 修复安装版把 v14 播放器误判为未知补丁、导致本地服务无法启用的问题。
- 已去除 OliviaSoul 软件界面水印和游戏音乐视频画面的 UID 水印。

## 本次主要更新

### 1. 下载更新与安装体验
- 使用 Windows 已启用的系统代理访问下载源，保留直连路径和完整性校验；下载速度仍取决于网络、代理节点和 GitHub，不承诺固定速率。
- 显示下载进度、速度和预计剩余时间，支持暂停、继续及断线续传。取消会清理本次下载文件，不删除以前完成的安装包。
- 检查更新与下载状态分开显示，取消提示不再覆盖新检查结果。当前版本较新时忽略旧下载任务，避免错误续传或降级安装；安装前再次校验任务、版本、文件大小和哈希。
- 更新按钮单排展示，安装确认及错误提示采用统一主题。支持“稍后安装”；启动安装失败可查看详情并重新校验。
- 安装向导提供简体中文/English：首次跟随系统显示语言，其他语言回退英文，可手动选择；升级记住上次选择，卸载沿用所选语言。管理界面仍为中文。

### 2. 客户端服务检查
- 合并重复的只读状态检查，使用非交互脚本调用；超时最多重试一次，并记录耗时。补丁写入不会自动重试。
- 清楚显示界面补丁 FE 与播放器 WP 的版本，旧补丁不再笼统显示“两边已挂载但状态不一致”。
- 未达到完整挂载状态时不再误报“服务已启用”；保留启停互斥、可信备份验证及失败恢复保护。

### 3. AI 配置和状态
- 保存的模型配置下次启动继续使用，后台检测一次；进入 AI 页面不会重复发送测试请求。
- 保留上次检测结果和时间，后台检测完成后自动刷新，不再长期卡在“正在检测”。
- 当前模型“保存并测试”成功后立即同步状态；模型、接口或密钥改变后不沿用不匹配的旧结果。
- “上次检测可用”不是当前在线保证。清除模型配置同时清除检测历史，不影响信件、曲库及名称纠错。本地模型服务仍需自行启动。

### 4. 管理页提醒圆点
- 选项卡右上角金色点提示新版本、任务完成，查看后消失；已读记录在当前浏览器配置中保留。
- 红色点提示模型、客户端或任务异常，问题解决后消失，查看不会掩盖故障。
- 悬停可查看原因，同时提供辅助功能标签。正常后台检测不制造新异常提醒。
- 管理页加载时静默检查一次公开版本，不自动下载安装、不额外调用 AI；更换浏览器配置、端口或清除浏览器数据可能重置已读记录。

### 5. 累计包含的播放、编辑与安全修复
- 保留原生写信、音乐小组件及信箱入口修复；针对客户端 `0.0.9.627`，FE v32、WebPlayer v13 及对应原生补丁。
- 修复上传作品媒体绑定、官方/本地播单交接约 2 秒中断、旧进度串入下一首、重复结束通知；切歌与重播进度归零，拖动与结束状态同步。暂停/停止结束当前演奏并恢复默认壁纸，播单按所选模式推进。
- 前后台共用名称/时段编辑与预览，优化预览读取和永久改名速度；改名不修改视频路径、作品 ID 或时段绑定。
- 整理左右布局、作品列表、记忆编辑、长模型名和窄窗口显示；支持文本框右键编辑。
- 保留服务启停、映射盘执行、托盘退出窗口联动、客户端补丁登记与卸载恢复；普通启动不自动继承其他旧安装的私人 AI 配置。
- 安装版卸载前恢复所有已登记且可验证的活动客户端补丁及严格匹配的 Steam 启动项。遇到路径、备份、哈希或权限异常会中止卸载，保留恢复材料，不改游戏 `usersettings.dat`。
- 完整包含 Node.js、转写与媒体运行时，不含游戏、曲库视频、私人配置、信件或 API Key。MIDI 生成已下线，仅导入现有有效 MP4。

## 下载与升级方法

附件：`OliviaSoul-2008.2.7-Setup.exe`（安装版）、`OliviaSoul-2008.2.7-Portable.zip`（便携版）、`SHA256SUMS.txt` 及使用/反馈说明。校验值以本次附件为准，不要使用旧包的哈希。

1. 关闭游戏，从托盘完全退出 OliviaSoul；备份整个 UserData 和外部音乐目录。
2. 安装版选择原独立安装目录覆盖安装；便携版完整解压到原目录。无需先卸载，不要同时运行两个版本。
3. 先打开 OliviaSoul，在“客户端与桌面”更新客户端补丁或重新启用服务，确认成功后再从 Steam 启动游戏。**仅覆盖软件安装包，不会自动补齐游戏内旧补丁。**
4. 后续先开 OliviaSoul 再开游戏。模型配置会保留，无需重新输入；本地 AI 服务需要自行运行。

[完整使用说明](https://github.com/coderscsy/linli/blob/main/source/local-service/packaging/使用说明.txt)

## 曲名与时段：请先预览核对

- 原始目录、清单可能标错歌名。软件不自动听歌识曲，请听一个代表片段确认后使用“永久保存曲名”纠错。
- 同一作品的三个时段视频共用一个歌曲名称；修改一次即可，原视频文件名保持不变。
- DEFAULT、ALT 或哈希文件名不能证明时段。无可靠标记时，请查看各片段画面并手动对应：白天 06:00–16:00、傍晚 16:00–20:00、夜晚 20:00–次日 06:00。保存后用于下次播放。
- 默认引用原视频目录，不自动迁移；请保留原目录和 UserData。网络盘/移动盘必须可访问，换电脑请同时备份媒体和名称纠错记录。

## 注意事项与验证边界

- 未配置代码签名，Windows 可能提示未知发布者。请核对可信来源及 SHA-256，不要关闭安全软件。
- 本机验收及自动测试不保证所有电脑、网络与后续游戏版本兼容。预览大视频、网络盘访问或首次安装 WebView2 可能需要等待。
- 压力测试曾捕获 Chromium 内存分配失败（`0xE0000008`），内存压力来源仍未确认。本次请求保护不等于证明已根治所有闪退；不要通过删除数据库、盲改虚拟内存或强行覆盖备份来排障。
- 卸载前退出游戏和 Steam；备份/哈希等检查失败时请按提示处理，不要绕过卸载保护直接删除目录。UserData 默认保留。
- 正式下载以本次 GitHub Release 为准；安装包沿用审核通过的原始文件，包内若有“审核阶段”字样仅是构建时的说明，功能及校验值未改变。
