# OliviaSoul R10.7 · 中转 API 兼容更新

程序版本保持 `2008.2.7`，更新标识为 `2008.2.7-linli.9`。提供完整安装包和便携包，包含 R10.6 全部功能；客户端补丁仍为 FE v44 / WebPlayer v18。

## R10.7 新增

- 模型名支持手动输入，模型列表查询改为可选；中转站与本地接口统一使用“通用兼容 API”档案。
- 支持完整 Chat Completions 地址、JSON 分段正文及 SSE 正文处理。
- 新增中文《API配置使用说明.md》，包含 seekai.cc 示例、接口地址与文档/状态页的区别、鉴权及常见错误说明；安装版与便携版均附带。

## R10.7 修复与优化

- 查询模型不再覆盖手填名称，查询失败仍可手动填写并测试。
- 非 DeepSeek 模型不再接收 DeepSeek 专用参数。
- 统一连通性检测、AI 导入、文本整理及 PowerShell 回信的正文判断；仅推理、截断、断流和错误响应不再当作成功结果。
- HTTP 400/422 明确拒绝 `max_tokens` 时，改用 `max_completion_tokens` 重试一次并保持原上限；认证或限流错误不触发参数重试。
- 校验接口地址，限制响应大小，禁止凭据请求跟随重定向；为 DeepSeek 推理检测预留正文输出预算。

接入范围：Chat Completions 兼容接口，不含 Claude Messages、Responses、Gemini 原生协议等；seekai.cc 为配置示例，尚未使用该用户密钥实测。

## R10.6 历史累计更新（原说明保留）

程序版本保持 `2008.2.7`，更新标识升为 `2008.2.7-linli.8`。累计包含 linli.7 及本轮更新，提供完整安装包和便携包。

以下为 R10.6 的功能与历史验证记录，随本版累计保留，不代表本轮重新进行游戏压力测试。

## 本次主要更新

### 1. 新增轻量桌面歌词

- 新增独立“歌词设置”选项卡；管理页、托盘“启用歌词”和游戏底部“词”按钮共用开关。默认关闭，重启保留选择，开启不会自动播放音乐。
- 支持为“我的上传”作品导入本地 LRC，按作品 ID 保存关联，修改曲名后无需重新导入。
- 同一作品的三个视频版本默认共用歌词，已有独立关联不覆盖；各版本时间偏移分别保存，也可更换为该版本专用的歌词。
- 跟随实际播放进度，支持播放途中开启、切歌、拖动进度、重播和循环定位。无歌词时显示曲名与“暂无歌词，尽情欣赏音乐”，缺少曲名时显示“正在播放”；停止、结束或状态失效时隐藏。
- 使用原生桌面窗口，不额外启动歌词程序或浏览器；关闭歌词不停止音乐，并释放歌词专用显示资源。

### 2. 新增歌词外观与桌面交互

- 支持横排、竖排、单行、双行，以及字体、字号、粗体和歌词颜色设置；保存窗口位置与锁定状态，横竖排分别记住位置。
- 工具栏采用 30×30 图标，横排加宽、圆角并居中，竖排工具栏与歌词居中显示。
- 未锁定时，鼠标悬浮显示暖炭灰底色和边框，移开后隐藏
- 锁定后悬浮时显示黑底解锁图标；管理页和托盘也可解除锁定。
- 歌词区域与工具栏空白处可拖动。
- 提供上一曲、暂停/继续和下一曲。歌词工具栏暂停保留歌词与位置，继续时从原进度播放；游戏原有停止演奏并返回默认壁纸的行为不变。
- 左箭头延后 0.5 秒，右箭头提前 0.5 秒，支持归零。
- 作品编辑器右下角“保存”和歌词区域按钮均可提交偏移，已保存偏移与工具栏同步。
- 文件选择控件中文化，文件名与按钮对齐；管理页与游戏内编辑器同步提供歌词导入入口。

### 3. 新增曲库移除

- 管理页与游戏“我的上传”歌曲外层增加“移除”按钮，管理页支持勾选后批量移除。
- 显示曲库总数和已选首数；已勾选歌曲的行内移除与顶部批量入口一致。确认框逐首显示完整曲名，支持长名称换行和多首滚动，完成后提示实际移除数量。
- 移除后同步清理曲库列表与播放列表，不删除原视频，保留曲名与歌词记录；手动重新导入可恢复，后台同步不会自动恢复。
- 源视频被删除或不可访问时提示播放失败，不自动删除曲库记录。

### 4. 客户端与曲库修复

- 修复已有曲库时，新导入歌曲被追加到列表末尾的问题；管理页与游戏按相同顺序即时刷新，保留搜索、已选项目和播放状态。
- 修复移除正在播放的用户歌曲后未续播的问题，按原队列位置播放下一首可用歌曲，兼容官方及用户歌曲；移除非当前歌曲不打断播放，暂停或空队列不自动播放。
- 修复移除后重新加入播单时，旧去重缓存导致歌曲不显示的问题。
- 曲库导入完成后即时通知管理页和游戏刷新；合并重叠刷新请求，防止旧结果覆盖新列表，保留当前搜索与播放状态。
- 修复移除正在播放的作品后，背景视频进度写回空进度条，以及进度清空被误当成拖动指令的问题。
- 修复直接选择单个 midi_… 作品文件夹时，将多个视频版本拆成不同作品的问题。兼容文件夹改名后的哈希视频缓存及同一文件名系列的时段版本；重新导入核验内容后保留曲名和作品身份，并恢复新路径播放。
- 修复管理窗口最大化时第一次关闭只隐藏内容、需再次关闭的问题。
- 已引用目录按作品来源去重显示，最近导入目录单独标注；移除后同步更新。旧作品来源不明时明确提示，自动监测仅覆盖最近导入目录。
- 修复管理页移除歌曲后游戏列表同步延迟、播放失败仍显示播放中，以及内部英文错误直接弹出的问题。
- 修复多目录导入后旧作品来源丢失的问题：分别保存作品来源，旧缓存失效时按内容身份核验原视频；不修改曲名、歌词绑定或原文件。
- 客户端补丁升级至 FE v44 / WebPlayer v18，支持曲库移除、歌词播放控制和暂停状态同步，保留已有进度节流、请求清理及会话隔离。
- 修复官方歌曲通过歌词工具栏暂停后歌词消失的问题，暂停保留曲名与工具栏，继续时恢复实际播放进度；游戏原有停止演奏行为不变。
- 补齐旧补丁识别和升级指引，避免将带补丁文件当作原始备份；保留可信备份验证和失败恢复保护。
- 修复引用导入、自动同步不必要地依赖游戏曲目保存路径的问题。引用导入不搬动视频，显式迁移仍需有效目标路径。
- 保留 linli.7 的曲目保存路径解析兼容、只读检查、重试和回退逻辑。
- 补齐托盘与管理页“开机自启动”的双向状态同步。

## 下载与升级方法

附件：`OliviaSoul-2008.2.7-Setup.exe`（安装版）、`OliviaSoul-2008.2.7-Portable.zip`（便携版）、`SHA256SUMS.txt` 及使用/反馈说明。

1. 关闭游戏，从托盘完全退出 OliviaSoul，备份整个 UserData 和外部音乐目录。
2. 安装版覆盖安装到原独立目录；便携版完整解压后运行 `OliviaSoul.exe`，不要在 ZIP 内启动，不要同时运行新旧版本。
3. 在“客户端与桌面”更新补丁至 **FE v44 / WebPlayer v18**，确认成功后再启动游戏。仅更新软件安装包不会自动补齐游戏中的旧补丁。
4. 在“歌词设置”启用歌词，在作品编辑页导入 LRC，再播放“我的上传”作品；游戏底部“词”按钮可开关歌词。

升级补充：无需先卸载旧版；后续先开 OliviaSoul 再开游戏，模型配置继续保留，本地 AI 服务仍需自行运行。校验值以本次附件为准，不要使用旧包的哈希。

## 曲名与时段：请先预览核对

- 原始目录、清单可能标错歌名。软件不自动听歌识曲，请听一个代表片段确认后使用“永久保存曲名”纠错。
- 同一作品的三个时段视频共用一个歌曲名称；修改一次即可，原视频文件名保持不变。
- DEFAULT、ALT 或哈希文件名不能证明时段。无可靠标记时，请查看各片段画面并手动对应：白天 06:00–16:00、傍晚 16:00–20:00、夜晚 20:00–次日 06:00。保存后用于下次播放。
- 默认引用原视频目录，不自动迁移；请保留原目录和 UserData。网络盘/移动盘必须可访问，换电脑请同时备份媒体和名称纠错记录。

## 歌词文件与偏移说明

- 歌词副本：`UserData/lyrics`；设置、关联及偏移：`UserData/database/olivia-local.sqlite`。升级与迁移请保留整个 UserData。
- 支持 UTF-8 和带 BOM 的 UTF-16 LRC，最大 256 KiB；异常文件给出提示，不影响音乐播放。
- 三个视频版本可共用文本，但偏移独立保存。钢琴改编、删节或重复段落不同的版本可能需要专用 LRC，整体偏移不能解决所有节奏差异。
- 默认引用原视频目录，不自动迁移；请保留原目录，网络盘或移动盘需保持可访问。
- 本次不包含全局快捷键、在线搜词、逐字精准高亮、翻译、AI 歌词生成或外部播放器识别。

播放问题请附播放模式及官方/上传切换顺序，下载问题请说明代理与失败阶段，并补充截图。日志还应移除密码和 Cookie。欢迎提交新功能的使用场景与优先级，详见随包《反馈指南.md》。
