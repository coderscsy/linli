# 桌面歌词（R10.6 / linli.8）

适用于 FE v44 / WebPlayer v18。先更新客户端补丁，再启动游戏。歌词默认关闭，不会自动播放音乐。

## 启用与导入

1. 管理页“歌词设置”、托盘“启用歌词”和游戏底部“词”按钮共用同一开关。
2. 在“我的上传”作品的“名称 / 时段”编辑器中展开歌词区域，选择 LRC 后保存。
3. 同一作品尚未关联的其他视频版本默认共用文本，已有独立关联不覆盖；每个版本的偏移分别保存，也可以更换专用 LRC。
4. 无歌词时显示曲名与“暂无歌词，尽情欣赏音乐”；歌词工具栏暂停保留歌词和当前进度，继续时从原进度播放。游戏原有停止演奏入口仍恢复默认壁纸。

## 外观与操作

- 支持横排、竖排、单行、双行、系统字体、字号、字重、颜色和不透明度；横竖排分别保存位置。
- 未锁定时悬浮显示工具栏、底色和边框，移开隐藏；歌词与工具栏空白处可拖动。
- 锁定后悬浮仅显示黑底解锁图标；也可从管理页或托盘解除锁定。
- 工具栏提供上一曲、暂停/继续、下一曲和歌词偏移控制。左箭头延后 0.5 秒，右箭头提前 0.5 秒，归零恢复本版本偏移。
- 提示位于鼠标下方，不接受鼠标点击。关闭歌词不停止音乐。

## 文件与数据

- 支持 UTF-8 和带 BOM 的 UTF-16 LRC，最大 256 KiB。
- 歌词副本位于 `UserData/lyrics`；设置、关联和偏移位于 `UserData/database/olivia-local.sqlite`。升级和迁移请保留整个 UserData。
- 修改曲名不会丢失歌词关联。UI 偏移正值延后、负值提前，只影响歌词、不改变音视频进度。
- 官方歌曲和没有关联 LRC 的作品也可显示曲名及工具栏；本版不提供在线搜词、自动识曲、逐字精准高亮、歌词翻译或外部播放器识别。
- 原唱 LRC 不一定匹配钢琴改编或删节版本，整体偏移无法修正全部节奏差异。
