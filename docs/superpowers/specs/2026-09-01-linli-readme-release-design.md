# Linli 独立 README 与安装包发布设计

## 目标

把 `coderscsy/linli` 作为当前离线增强版的独立发布入口，不再沿用上游项目的 README 叙事和下载地址；同时提供普通用户可直接下载安装的 Windows 安装包与便携包。

## 发布身份

- GitHub 仓库：`https://github.com/coderscsy/linli`
- 默认分支：`main`
- Release 标签：`2008.2.7-linli.1`
- 程序内部版本继续使用项目固定版本 `2008.2.7`，避免破坏既有版本校验和安装器规则。
- README 标题和正文使用“林离离线增强版”作为本仓库身份。

## README 结构

README 全文重新编写，不复用现有个人叙事、旧项目统计、旧仓库下载链接或“最终里程碑”长文。新文档保持面向普通用户，结构如下：

1. 项目简介与适用范围。
2. GitHub Release 的安装版和便携版下载入口。
3. 当前功能：
   - 离线写信、读取文字回信和本地记忆；
   - DeepSeek 与本地 OpenAI 兼容接口手动切换；
   - 默认本地 Gemma 档案；
   - MIDI、音乐入口和本地歌单；
   - `.soul` 备份与恢复；
   - 视频回信附件上传、保存和播放；
   - 本地 Whisper 音视频转写。
4. 首次使用步骤：安装位置、模型配置、导入记忆、选择客户端、启用服务。
5. 功能边界与已知限制：
   - 不包含官方服务器数据；
   - 不包含游戏客户端资源、个人信件、密钥和数据库；
   - 视频附件链路可用，但尚不能自动生成林离人物语音视频；
   - 本地模型由使用者自行提供和维护；
   - 安装目录不能是游戏目录。
6. 开发验证与源码构建入口。
7. 简短上游来源致谢、学习交流声明与隐私说明。

## 构建产物

在 I 盘工作树中运行现有 Windows 发布脚本，输出目录明确指定到 I 盘。发布资产为：

- `OliviaSoul-2008.2.7-Setup.exe`
- `OliviaSoul-2008.2.7-Portable.zip`
- `SHA256SUMS.txt`
- `使用说明.txt`

Release 标题使用“林离离线增强版 2008.2.7-linli.1”。Release 正文概述双模型手动切换、离线信件与记忆、MIDI/音乐恢复和视频附件能力，并明确自动人物视频生成尚未实现。

## 数据与安全边界

- 构建、缓存和正式产物只写入 I 盘；不得把大型产物放到 C 盘。
- `Z:\SteamLibrary\steamapps\common\BSide Olivia Lin Test` 与 `I:\Backups\BSide-Olivia-Lin-2026-08-31` 保持只读。
- 发布包不得包含 `.cursor/secrets`、`.env`、SQLite 数据库、日志、缓存、个人信件、记忆文件、游戏资源或 API Key。
- GitHub Release 只上传通过验证的四项发布资产。

## 验证

发布前必须完成：

1. 完整 Node 测试套件通过。
2. Windows 构建脚本成功退出。
3. 安装包与便携包均存在且大小非零。
4. `SHA256SUMS.txt` 中的哈希与重新计算结果一致。
5. 便携包解压后存在可执行文件、模型调用模块、管理页资源和 PowerShell 共享调用器。
6. 对发布目录执行敏感文件名检查。
7. README 中所有仓库与 Release 链接指向 `coderscsy/linli`。
8. 推送后核对远端 `main` SHA；创建 Release 后核对标签、资产名称、资产数量和下载 URL。

## 失败处理

- 缺少构建依赖时只在 I 盘安装或缓存；不能因此改用 C 盘存放产物。
- 任一测试、构建、哈希或敏感文件检查失败时停止发布，保留诊断信息并修复后重新验证。
- 不覆盖已经存在且指向不同提交的同名标签或 Release；发现冲突时停止并报告。
- 不使用强制推送。
